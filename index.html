Roles & Permissions

Every capability in the app is a checkbox. Tick one to grant it to that role — the change applies immediately, with no rebuild.

What this does, and what it does not. These permissions decide what each role is shown and offered, which is what governs day-to-day use. They are not a security boundary: this build keeps all data in the browser, so anyone with developer tools can read it or change their own role. Enforcing these rules for real requires re-checking them on a server that holds the data.
